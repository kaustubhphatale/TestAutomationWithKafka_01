## 🔭 Currently Working On
I’m building a **Microservices & Kafka Test Automation Framework** to explore a practical challenge in event-driven systems:

**How do we verify that a business transaction succeeds beyond the initial API response?**

Built with **Playwright Test, TypeScript, KafkaJS, and Docker Compose**, the framework provides a foundation for testing service APIs and Kafka-based workflows.

The current examples cover:

🔹 Creating an order through an API and checking the emitted Kafka event  
🔹 Matching events with correlation IDs  
🔹 Validating event payloads against a JSON Schema  
🔹 Waiting for asynchronous outcomes with deadlines instead of fixed sleeps  
🔹 Running contract checks and setting up local Kafka for development  
🔹 Providing a GitHub Actions workflow template for CI  

The framework is designed to grow. The roadmap includes Schema Registry compatibility checks, DLQ and broker recovery automation, OpenTelemetry trace correlation, and load testing.

This project reflects how I think about Quality Engineering: tests should help us validate the full business flow—not just whether an endpoint returned a successful status.

I’m building on 15+ years in software testing and automation, and continuing to learn by creating and evolving practical frameworks.
